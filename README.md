# 🎮 Game Hub

A simple tabbed browser-game launcher. Built with plain HTML, CSS, and JavaScript — no build step, no dependencies.

## Features
- 🗂️ Multi-tab system (open, close, switch between games)
- 🔍 Live search filter
- 📌 Sidebar with all games
- 🖼️ Games load in sandboxed iframes
- 🎨 Dark theme
